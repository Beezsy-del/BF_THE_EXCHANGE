### Idea
- **MORPH is a creative studio where every pixel is programmable.** You draw pixel art with a real pixel editor, with a small drawing language, or by typing a word. Then you bring it to life with mathematics: a sine wave makes a tree sway, distance from the centre makes ripples, smooth noise makes liquid marble, and a spring makes pixels flow around your mouse.
- **Drawing decides what exists; formulas decide how it behaves.** Every motion is a formula you can edit either as maths or as visual blocks (Time → Sine → × 10 → Move). Both are the same thing underneath and always stay in sync.
- **Draw → Animate → Explore:** 10 ways to animate any drawing (Breeze, Ripple, Breathe, Swirl, Dissolve…), pixel or particle rendering, **Evolve** (four mutated variations to choose from), full-screen formula art (marble, aurora, contours, silk ribbons), and a gallery of living pieces: Blossom Night, Ocean Sunset, Golden Bloom, Jellyfish, Living Type.
- Calm by design: motion glides, changes crossfade, with an optional generative ambient soundtrack. Export PNG, record video, save and open projects.

### How to Run
- **Prerequisites:** [Node.js](https://nodejs.org/) 18 or newer (tested on Node 22) and npm. A modern browser (Chrome, Edge or Firefox).
- **Installation steps:**
  ```bash
  git clone https://github.com/shashwat106/BF_THE_EXCHANGE.git
  cd BF_THE_EXCHANGE
  npm install
  ```
- **Exact commands to run the project locally:**
  ```bash
  npm run dev        # opens on http://localhost:5181
  ```
  Optional:
  ```bash
  npm test           # 45 automated tests (maths fuzzing, language, workflow, security)
  npm run build      # production build in dist/
  npm run preview    # serve the production build locally
  ```
- **Controls:** Space = play/pause · R = reset · F = fullscreen. In Paint: B pencil, E eraser, G fill, L line, U rectangle, O ellipse, I colour picker, M mirror, [ ] brush size, Ctrl+Z / Ctrl+Y undo/redo.
